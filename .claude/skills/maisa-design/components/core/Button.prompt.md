Botão de ação: use `primary` para a ação principal da tela (só uma), `secondary` para alternativas e `ghost` em barras de ferramenta.

```jsx
<Button variant="primary" size="lg" iconRight={<Icon name="arrow-right" size={18} />}>
  Começar de graça
</Button>
```

Variantes: `primary` (verde sólido) · `secondary` (branco com borda) · `soft` (verde claro) · `ghost` · `accent` (âmbar, só em marketing) · `danger`. Tamanhos `sm|md|lg` (34/42/52px). `block` para largura total em mobile. Press state abaixa 1px — não remova.
